Use on your phone

Add to your Home Screen

On iPhone, open this website in Safari, tap Share, then Add to Home Screen. On Android, use your browser’s Install app option.

Share from Google Maps on iPhone

Create a Shortcut called Check hygiene and turn on Show in Share Sheet. Accept URLs and text. Add these actions:

  1. Get URLs from Input using Shortcut Input.
  2. Get Item from List: First Item.
  3. Expand URL using that URL.
  4. URL Encode the expanded URL.
  5. Text: paste the address below, then insert the URL Encoded Text variable at the end.
  6. Open URLs using the Text.

After the final =, insert the variable as a coloured token. Then use Google Maps → Share → Check hygiene. If Maps returns an ID-only link, add the restaurant name or postcode.

Android sharing

Once installed in a supported browser, this app can appear in the Share menu. A shared restaurant name works immediately. A short link on its own may need its name added.

Pasting links

Full Google Maps place links usually include the restaurant name and pin. Short links such as maps.app.goo.gl/… hide that information. The iPhone Shortcut expands them first. You can also paste the name and postcode directly.

About the ratings

England, Wales and Northern Ireland use ratings from 0 to 5. Scotland uses its own pass/improvement scheme. A rating describes hygiene at the last inspection, and is not a review of food quality or a guarantee about allergens.

Saved ratings show when they were checked and refresh when you open them online. Names may differ between Google Maps and council records. Always check the address.

Tap Near me with an empty search to browse local businesses. Map pins show the loaded results; use Load more to see more matches. Businesses without coordinates can be found by name or postcode.

Searches go to the FSA. Location is used only when you tap Near me. Opening the map requests tiles from OpenStreetMap. Recent checks stay on this device. No analytics, accounts or advertising.
